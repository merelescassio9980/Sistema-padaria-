# Bella Massa
## Sobre
Este software, escrito em C tem como objetivo ser a ferramenta de vendas e gestão de uma padaria. 
## Funções
Cadastro de clube de clientes.
Plataforma de vendas.
Carrinho de compras.
Plataforma de cupom, desconto e pagamento.
Relatório de vendas, quantitativo e financeiro.
## Produção
Produzido por alunos do curso de graduação de engenharia de software da UniCesumar de Ponta Grossa - PR.
